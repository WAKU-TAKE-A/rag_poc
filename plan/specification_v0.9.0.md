# RAG PoC システム仕様書 (v0.9.0)

## 1. 概要
本システムは、大量のドキュメント（PDF、PowerPoint、Markdownなど）から必要な情報を高速に検索し、LLM（大規模言語モデル）を用いてユーザーの質問に回答するRAG（Retrieval-Augmented Generation：検索拡張生成）のProof of Concept（概念実証）システムです。

## 2. システム構成・アーキテクチャ
システムは以下の5つの主要なステップ（パイプライン）で構成されています。

### 2.1. パース (Parse)
- **機能**: 様々なフォーマットのファイルを解析し、標準的なMarkdown形式に変換します。
- **使用ライブラリ**: `Docling`
- **特徴**: OCR機能のON/OFFが可能。巨大なPDFの処理時にメモリ不足（OOM）を防ぐため、事前に指定ページ数で分割する機能（`pypdf`使用）も備えています。

### 2.2. チャンク化 (Chunk)
- **機能**: パースされたMarkdownファイルを、見出し（Heading）レベルに基づいて意味のある塊（チャンク）に分割します。
- **特徴**: 分割する見出しレベル（デフォルトは2: `##`）を設定可能。

### 2.3. 埋め込み (Embed)
- **機能**: 分割されたテキストチャンクをベクトルデータに変換します。
- **使用モデル**: OpenAI `text-embedding-3-small` (1536次元)

### 2.4. 検索 (Search) - ハイブリッド検索
- **キーワード検索 (BM25)**: `Whoosh` を使用。日本語形態素解析には `Janome` を採用。
- **ベクトル検索**: `Qdrant` (ローカル/ディスク保存モード) を使用。
- **統合**: 両者の結果を組み合わせることで、キーワードの一致と意味の類似性の両面から高精度な検索を実現します。

### 2.5. 回答生成 (Ask)
- **機能**: 検索でヒットした上位のチャンク（Top-K）をコンテキストとしてLLMに渡し、回答を生成します。
- **使用モデル**: OpenAI `gpt-4o-mini`
- **特徴**: 厳密な回答（推測禁止）から、文脈を汲み取った柔軟な回答（推測許可）まで、プロンプトと温度で調整可能です。

## 3. 差分更新（Sync）機能
- ファイルのハッシュ値（MD5）を利用して、`input/` フォルダ内のファイルの変更・追加・削除を検知します。
- 変更があったファイルのみを連鎖的に処理し、削除されたファイルに関連する中間ファイルはお掃除します。
- 状態は `sync_state.json` に記録されます。

## 4. コマンドリファレンス

| コマンド | 引数 | 説明 |
| :--- | :--- | :--- |
| `sync` | なし | フォルダ内の全自動差分更新を実行 |
| `parse` | `[ファイルパス]` | 指定ファイルをMarkdownに変換 |
| `chunk` | `[ファイルパス] [--level N]` | 指定ファイルをチャンク分割 |
| `embed` | `[ファイルパス]` | 指定チャンクをベクトル化 |
| `search` | `[クエリ]` | 検索のみを実行しヒット件数を表示 |
| `ask` | `[質問]` | 検索＋回答生成を実行 |
| `config` | `[各種オプション]` | 設定の確認および変更 |
| `split` | `[PDFパス] [--pages N]`| 巨大なPDFを分割 |

## 5. 設定項目 (`config.json`)

| キー | デフォルト値 | 説明 |
| :--- | :--- | :--- |
| `do_ocr` | `false` | パース時のOCR有効化フラグ |
| `pdf_split_pages` | `20` | PDF分割時の1ファイルあたりのページ数 |
| `chunk_level` | `2` | チャンク分割を行う見出しレベル |
| `search_limit` | `7` | 検索時に取得する上位件数 (Top-K) |
| `llm_model` | `gpt-4o-mini` | 回答生成に使用するLLMモデル |
| `llm_temperature` | `0.3` | 生成時の温度（ランダム性） |
| `llm_system_prompt` | （略） | システムロールへの指示 |
| `llm_user_prompt_template`| （略） | ユーザープロンプトのテンプレート |
