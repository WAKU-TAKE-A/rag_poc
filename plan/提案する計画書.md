# AI用計画書 v0  
## RAGのPoC

---

# 1. プロジェクト概要

本プロジェクトは、RAG(Retrieval Augmented Generation)の内部処理を可視化・説明可能にするためのCLIベースPoCである。

目的は以下。

- 文書がどのように構造化されるかを確認する
- chunkがどのように生成されるかを確認する
- なぜ検索結果がヒットしたかを説明可能にする
- 生成AI(Codex等)による自動実装しやすい構成にする

本PoCでは、過剰な高度化を避ける。

# 5. 共通中間形式

v0ではMarkdownを主中間形式とする。

理由：

- 可読性が高い
- diff確認しやすい
- AI実装しやすい
- explainable

JSON ASTの高度設計はv0では行わない。

# 10. CLI仕様

CLIは工程分離型とする。

---

## parse

入力文書をMarkdown化する。

例：

```bash
python main.py parse sample.pdf
```

---

## chunk

Markdownからchunk生成する。

例：

```bash
python main.py chunk parsed/sample.md
```

---

## embed

chunkへembedding付与する。

例：

```bash
python main.py embed chunks/sample.json
```

---

## search

検索実行する。

例：

```bash
python main.py search "timeout変更"
```
